# 🔥 Brunão Costela no Bafo — Cardápio Digital

Cardápio digital online do **Brunão Costela no Bafo**, nosso delivery de costela
assada no bafo.

O objetivo é simples: o cliente abre um link no celular, monta o pedido e envia
direto pelo WhatsApp da loja — sem app para instalar, sem cadastro e sem taxa de
marketplace.

## Status

Projeto recém-criado. Esta é a estrutura inicial do repositório; o cardápio em si
vem na sequência.

## Stack

HTML, CSS e JavaScript puro. Sem framework e sem etapa de build, para que o site
possa ser publicado de graça no GitHub Pages e editado por qualquer pessoa da
equipe.
